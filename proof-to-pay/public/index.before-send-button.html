      PayPal Integration & Workspace Settings

      Proof-to-Pay manages all PayPal OAuth 2.0 credentials strictly on the backend server (.env) and never stores secrets in browser storage or frontend code.

      1. Local Demo / Fixture Mode ACTIVE

      Used for local evaluation when PayPal Sandbox keys are not set in .env. All invoices and links are clearly labeled as simulated and are never marked as real PayPal transactions.

      2. Connected PayPal Sandbox Mode CONFIGURE IN .ENV

      Connects to https://api-m.sandbox.paypal.com via server-side OAuth 2.0 to create, send, and verify real PayPal Sandbox invoices and webhooks.

      3. Live PayPal Mode PRODUCTION

      Active only when PAYPAL_ENV=live and production credentials are configured on a secure backend server.

      How to Enable Connected PayPal Sandbox Mode (Server-Side .env):
      PAYPAL_ENV=sandbox
PAYPAL_API_BASE_URL=https://api-m.sandbox.paypal.com
PAYPAL_CLIENT_ID=your_paypal_sandbox_client_id
PAYPAL_CLIENT_SECRET=your_paypal_sandbox_client_secret
PAYPAL_INVOICER_EMAIL=sb-merchant@business.example.com
PAYPAL_WEBHOOK_ID=your_paypal_sandbox_webhook_id
